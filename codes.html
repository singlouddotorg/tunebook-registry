Frequently asked questions

What the codes, symbols, and badges on each book's page actually mean, and a quick sketch of the broader project this Registry is a read-only window into. This page sticks to the broad strokes - things settled enough to stay true even as the details of the underlying apps keep changing.

What's a Work Code? What's an Edition Code?

A Work is a book in the broad sense - the ongoing, evolving thing, independent of any one printing of it. The Sacred Harp is a Work; it's existed as many different, real editions over nearly two centuries, each with its own compilers, revisions, and additions, but they're all still recognizably the same book. A Work Code is a short, stable abbreviation for that ongoing thing - a few letters, not tied to any particular year.

An Edition Code is more specific: a Work Code plus the year that identifies one particular printing. That's the code you'll actually see most often here, since it's what distinguishes the book someone might really own and sing from.

SHM the Work  →  SHM1991 SHM2025 two real Editions of it

Some books also carry a separate SHMHA code - the abbreviation already used in the printed Sacred Harp Minutes Book, from before this project existed. Where one applies, it's shown alongside the Work Code, not in place of it - two different code systems tracking the same real books, kept side by side rather than merged into one.

What do the circled numbers next to a book's title mean?

Shape-note singing traditions use a small set of distinct note shapes - rather than plain ovals - to make sight-singing easier without formal training. Different traditions settled on different numbers of shapes for the same underlying scale. The circled digit is a quick, at-a-glance signal for which system a given book uses, nothing more.

❹ Four-shape - the older system, and the one The Sacred Harp itself uses.
❼ Seven-shape - a later system, used by a number of other real shape-note books.

What do the "Level 1 / 2 / 3" badges mean?

This is a plain, honest signal of how much has actually been documented about a book so far - not a judgment of the book itself, and not a ranking of one book against another. It's meant to move forward gradually, one step at a time, as real research gets done.

Level 1 A bare record - title, compiler, a rough date. No page index yet.
Level 2 A complete page index: every page matched to its song title, straight through the book.
Level 3 Level 2, plus real scholarly detail - meter, key, scripture reference, who wrote the text and the music, copyright status, and, for the book as a whole, things like publication history and sources.

Level 2 is already genuinely useful on its own - it's what's needed to reference a specific page during a real singing. Level 3 takes real research time, so it's filled in unevenly by design, sometimes song by song within the same book, rather than all at once.

What are "Minutes" and "Tunebooks"?

This Registry is a read-only mirror of data that lives in a small, separate, still-actively-developed project: two companion apps, plus the tunebook data itself.

Minutes

For logging a real singing as it happens - who led which song, on which page - and later compiling that into a finished, publishable set of minutes for the singing.

Tunebooks

The editing tool behind the tunebook data itself: adding a new book, building out its page index, and layering on the richer Level 3 detail this Registry shows when it's there.

Both are plain HTML files, opened by double-clicking - no install, no account, no server required - alongside a couple of shared data files they load from the same folder. This Registry is a separate, public, browsable companion to that same underlying data, meant purely for reference; nothing here writes back to it.

I found an error, or a book that should be here isn't. Now what?

This project is still actively growing, and corrections are genuinely welcome - a quick email is the most reliable way to flag anything, whether it's a wrong page number, a book missing entirely, or something on this page that could stand to be clearer.
