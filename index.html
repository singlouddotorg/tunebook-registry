Tunebook Registry

Every book, page by page

A browsable index of the shape-note tunebooks this project has indexed so far — full titles, editions, and every page's song content. This is a read-only companion to the Minutes / Tunebooks, built from the exact same data file Capture and Compile use to log and publish real singing minutes. Spot an error or have a correction? Let us know — this project is still growing and every correction helps.

A note on how complete this is: some books here have been verified page by page against the actual printed book; others are still based solely on that book's own printed index, and haven't been checked page by page yet. Song-level detail — meter, key, and text/music attribution — is filled in unevenly for the same reason, and more will be added over time as that verification happens. Every book's own page lists both a SingLoud.org Work Code and, where one exists, a separate SHMHA code (the abbreviation used in the printed Sacred Harp Minutes Book) — two different code systems tracking the same books. See the Code Reference page for the full list of both.
